# 🌟 VolunteerHub - SVECW Campus Volunteering Portal

Official campus community service and volunteer management platform for **Shri Vishnu Engineering College for Women (SVECW)**, Bhimavaram.

---

## 📌 Features

- 🏛️ **Official SVECW Portal Theme**: Tailored for Shri Vishnu Engineering College for Women, featuring authentic student profiles and faculty coordinators.
- 🎯 **Explore Drives**: Discover upcoming volunteering opportunities (NSS Blood Donation, Green Miyawaki Plantation, Tech Mentorship, Elder Care, etc.).
- 📝 **1-Click Event Registration & Passes**: Register for drives with real-time slot counters, instant confirmation passes, and unique passcodes.
- 📊 **Leaderboard & Honor Roll**: Real-time student rankings based on verified service hours and karma points with bronze, silver, and gold tiers.
- 🎓 **Student Dashboard & Digital Certificates**: Track attended drives, verified service hours, digital achievement badges, and printable merit certificates with QR validation.
- 📋 **Club Organizer Desk**: Coordinators can create new campus drives, manage volunteer rosters, award credits, and export volunteer lists.
- 📢 **Campus Bulletins**: Pinned circulars, alerts, and priority announcements from NSS and Student Welfare wings.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Lucide Icons, Canvas Confetti, Vanilla CSS Design System
- **Backend**: Node.js, Express.js, Resilient High-Performance JSON Store & MongoDB support
- **Styling**: Aurora Dark Mode Theme, Glassmorphism, Responsive CSS

---

## 🚀 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### 2. Installation & Setup

#### Backend:
```bash
cd server
npm install
npm start
```
*Backend runs on `http://localhost:5000`*

#### Frontend:
```bash
cd client
npm install
npm run dev
```
*Frontend runs on `http://localhost:3000`*
